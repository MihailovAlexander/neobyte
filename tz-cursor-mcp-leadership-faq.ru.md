## 1. Стоимость

### 1.3 Что сознательно не включаем

## Лицензии фирменного поиска / ИИ-продуктов **1С** (отдельные коммерческие продукты фирмы «1С») **в бюджет не закладываем.**

По состоянию на сентябрь 2026 продукт находится в стадии тестирования; **фирма «1С» планирует сообщить о стоимости не ранее октября 2026.** Старт проекта от этих лицензий **не зависит.**

## 2. Конфиденциальность и ИИ

**Что не попадает в контур проекта:** боевые информационные базы и данные клиентов.

**Что хранится у нас:** выгрузки конфигураций (код/метаданные) и построенный по ним поисковый индекс - на сервере компании.

**Что может уходить во внешние ИИ-сервисы при работе:** текст вопроса и необходимые для ответа **фрагменты** кода/метаданных из выгрузок. Это свойство любого такого инструмента; полностью исключить передачу фрагментов контекста в облако модели при его использовании нельзя - поэтому мы и не обещаем «ничего никогда не уйдёт».

**Какие ИИ-провайдеры / сервисы могут это обрабатывать**


| Сервис                                                                                     | Роль                                      | Что может получать                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Cursor**                                                                                 | ИИ в редакторе для IT                     | Вопрос и фрагменты контекста из открытой работы; дальше Cursor направляет запрос к выбранной модели (типично Anthropic, OpenAI, Google и др. - в рамках моделей, доступных в Cursor) |
| **Маршрутизатор моделей для чата и построения поиска** (на старте - OpenRouter или аналог) | Ответы веб-чата и эмбеддинги для индекса  | Текст вопроса / фрагменты для ответа в чате; текст для построения поискового индекса                                                                                                 |
| **Наш сервер**                                                                             | Хранение выгрузок, индексов, журнала чата | Обрабатывает данные **у нас**; сам по себе не является внешним ИИ-провайдером                                                                                                        |


Полные выгрузки конфигураций и индексы **не** передаются целиком в облако как архив: уходит только то, что нужно для конкретного запроса или ночного построения поиска.  
Состав разрешённых моделей внутри Cursor / OpenRouter можно сузить правилами проекта и решением Cyber (белый список). Смена конкретной модели внутри уже согласованных провайдеров - рабочая настройка, не отдельный проект.

**Обучение моделей:** на выбранном тарифе Cursor включаем доступный режим конфиденциальности; по публичной политике вендора при таком режиме код не используется для обучения. Условия по OpenRouter и выбранным моделям - по их политикам и договору, кажется там был флаг которым можно явно запретить можелям обучаться на наших данных, можно взвести его.

**Правила использования:** запрет вставлять пароли, ПДн и выгрузки из боевых баз. Журнал вопросов веб-чата - у нас.

## 3. Доступ

Согласны усилить модель относительно «только сеть + ключ».

**Принципы (детали - с IT и Cyber):**

- разделение: IT (редактор и поиск) и бизнес-пользователи (только чат-справка) - без доступа бизнеса к файлам кода и администрированию;
- MFA - в соответствии с уже принятыми в компании стандартами (VPN / корпоративный вход); для чата - корпоративная учётная запись;
- выдача и отзыв доступа - через IT при приёме/увольнении; админ-доступ - не менее чем у двух сотрудников;
- права разработчиков/аналитиков - чтение; изменение выгрузок на сервере - только администрирование.

Конкретные группы каталога, шаблоны заявок и интеграция с SSO - предмет технического совещания, не предмет этого ответа.

## 4. Инфраструктура

Сравниваем площадки **по одинаковому профилю** (мощность, диски, бэкап) с учётом безопасности, интеграции, эксплуатации и стоимости.


| Вариант                                               | Позиция                                                                                                                               |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Выделенный сервер рыночного класса (ориентир Hetzner) | Разумный по цене; подходит под ночную нагрузку поиска                                                                                 |
| Azure                                                 | Может быть предпочтительнее по интеграции и привычным процессам IT - если сопоставимый профиль после расчёта IT укладывается в бюджет |
| ITG (текущий) (~$960/мес только compute)              | Существенно дороже при сопоставимой/меньшей пользе; как основной вариант не предлагаем                                                |

## 5. Ответственность и поддержка


| Область                                      | Кто                     |
| -------------------------------------------- | ----------------------- |
| Внедрение и прикладная поддержка поиска/чата | Александр               |
| Сервер, сеть, доступы, обновления ОС         | Системный администратор |
| Политики безопасности                        | Cyber / Security        |
| Бюджет и приоритеты продукта                 | Владелец продукта 1С    |


Зависимость от одного человека снимаем так: второй администратор с первого промышленного дня; инструкции по восстановлению и выдаче доступа; секреты - в корпоративном хранилище, не «на одном ноутбуке».

Александр отвечает за внедрение и прикладную часть, **не** является единственной точкой отказа по инфраструктуре и доступам.
