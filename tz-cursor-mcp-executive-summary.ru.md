# Зачем внедрять Cursor и поиск по 1С - кратко для руководства

**Версия:** 3.1 · **Дата:** 2026-09-03

---

## О чём решение

Дать команде 1С помощника на базе ИИ, который опирается на **наши** конфигурации - не на общий публичный чат.

**Просим утвердить:**
- инструменты для **15** разработчиков и аналитиков;
- позже - **чат-справку для до 50** пользователей 1С (в том же бюджетном контуре);
- сервер под контролем компании;
- правило: **боевые базы с данными клиентов не подключаем.**

---

## Проблема

Знания по 15 конфигурациям размазаны по людям; поиск «где это в системе» занимает много времени; одни и те же вопросы пользователей отвлекают аналитиков от проектов.

---

## Что получим

| Для кого | Что |
|----------|-----|
| IT (15 чел.) | Cursor + общий поиск по выгрузкам конфигураций на нашем сервере |
| Пользователи (до 50) | Веб-чат-справка «как сделать / как работает» |
| Компания | Исходники и индекс у нас; доступ через корпоративные правила; отзыв при увольнении |

---

## Деньги

| | |
|-|-|
| Ориентир на год | около **$16 тыс.** внешних затрат |
| Старт (разово) | порядка **$230-310** (MCP ~7 000-8 500 ₽ / ~$80-110 + setup хостера при необходимости) - внутри годового ориентира |
| Установка | своими силами, в сумму не входит |
| Cursor | $20/чел/мес (компенсация) |

**Лицензии коммерческих продуктов фирмы «1С»** по поиску/ИИ **не включены:** продукт в тестировании, официальный прайс 1С - не ранее октября 2026. Старт от них не зависит.  
Разбивка - в [ответе на вопросы](tz-cursor-mcp-leadership-faq.ru.md) §1.

Площадку сервера (выделенный сервер рыночного класса или наш Azure) согласуем с IT в рамках того же ориентира. Дорогое предложение ITG (~$960/мес) как основной вариант не предлагаем.

---

## Как внедряем

1. Утверждаем идею, бюджетный ориентир и правило про боевые базы.  
2. Пилот для нескольких человек и конфигураций.  
3. При подтверждённой пользе - вся IT-команда.  
4. Чат - поэтапно, после согласования доступа с IT/Cyber.

После пилота можно остановиться.

---

## Риски - коротко

| Риск | Подход |
|------|--------|
| Фрагменты кода в облаке ИИ | Неизбежно при работе инструмента; режим конфиденциальности вендора; запрет паролей и данных клиентов в вопросах |
| Утечка через чат | Нет боевых баз; журнал; поэтапное открытие |
| Стоимость | Держим ориентир ~$16 тыс./год; без выдуманных лицензий 1С |

---

## Просьба

> Утвердить запуск Cursor и поиска по нашим конфигурациям для IT-команды и (поэтапно) веб-чат-справки для пользователей, без подключения боевых баз, с бюджетным ориентиром около **$16 тыс./год** внешних затрат.
