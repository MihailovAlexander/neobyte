# Зачем внедрять Cursor и поиск по 1С — кратко для руководства

**Версия:** 2.0 · **Дата:** 2026-08-27  
**Подробности:** [техническое описание](tz-cursor-mcp-team.ru.md) · [оценка рисков и управления](tz-cursor-mcp-governance-assessment.ru.md)

## О чём решение

Дать команде 1С и пользователям **помощника на базе искусственного интеллекта**, который знает **наши** 15 конфигураций — не общий ChatGPT «из интернета».

**Сейчас просим утвердить:**
- инструмент для **15** разработчиков и аналитиков;
- **чат-справку для до 50** обычных пользователей 1С;
- сервер у нас (рекомендуем Hetzner ~€259/мес);
- правила безопасности (боевые базы с данными клиентов **не** подключаем).

---

## Проблема

| Сейчас | Что это значит для бизнеса |
|--------|----------------------------|
| 15 разных конфигураций, код меняется каждый день | Знания размазаны по людям |
| Поиск «где это в системе» занимает часы | Доработки идут медленнее |
| Новичок долго входит в курс дела | Дорогое обучение |
| 50 пользователей одни и те же вопросы аналитикам | Аналитики отвлекаются от проектов |

---

## Что получим

| Для кого | Что появится |
|----------|--------------|
| Разработчики и аналитики (15 чел.) | Редактор **Cursor** + общий «мозг» по всем конфигурациям на нашем сервере |
| Пользователи 1С (до 50 чел.) | Простой **веб-чат**: «как сделать / как работает» без звонка аналитику |
| Компания | Индексы и исходники на **своём** сервере; доступ только через корпоративную сеть; при увольнении доступ отключается |

Боевые базы с реальными данными клиентов к чату и к «живому» подключению **не** даём. Только выгрузки кода и (по желанию позже) **тестовые** копии.

---

## Деньги

| | |
|-|-|
| В месяц (полный контур) | примерно **$830–1 140** |
| В год | примерно **$15–16 тыс.** + лицензии на поисковые серверы 1С (уточняются) |
| Сервер | ~€259/мес (Hetzner). Предложение ITG на $960/мес **невыгодно** |
| Работы по установке | своими силами, в смету не входят |
| Cursor | $20/чел/мес (компенсация в зарплате) |

Для сравнения: это заметно меньше стоимости **половины** одного специалиста 1С, а польза — на всю команду и пользователей.

**Окупаемость (оценка):** экономия времени IT порядка **$4–10 тыс./мес** при расходе ~$1 тыс. — плюс меньше нагрузки на аналитиков от пользователей.

---

## Как внедряем (без «всё сразу»)

1. **Сейчас утверждаем** идею, бюджет и правила безопасности (включая чат на 50 человек).  
2. Сначала — пилот для нескольких человек и нескольких конфигураций.  
3. Если польза подтвердилась — на всех 15 IT.  
4. Затем — чат: сначала 10–15 пользователей, проверка безопасности, потом до 50.

Остановиться после пилота можно — это не «всё или ничего».

---

## Риски — коротко

| Риск | Как закрываем |
|------|----------------|
| Уйдёт ли код в облако ИИ | Частично да (как в любом Cursor) — включаем режим приватности, запрещаем вставлять пароли и данные клиентов |
| Утечка через чат пользователей | Нет доступа к боевым базам; фильтр персональных данных; журнал всех вопросов |
| Дорого | Берём дешёвый выделенный сервер, не дорогую виртуалку ITG |

---

## Просьба к руководству

> Утвердить запуск: Cursor и поиск по 15 конфигурациям для IT-команды **и** веб-чат-справку для до 50 пользователей, без подключения боевых баз, с бюджетом около **$15–16 тыс./год** (+ лицензии поиска), поэтапно и с проверкой безопасности перед открытием чата всем пользователям.
