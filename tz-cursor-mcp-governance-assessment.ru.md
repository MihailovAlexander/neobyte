## Что утверждаем сейчас

| Входит в решение сейчас | Не входит (решим позже при необходимости) |
|-------------------------|-------------------------------------------|
| Сервер с «памятью» по 15 конфигурациям | Подключение **боевых** баз с данными клиентов |
| Cursor для 15 человек IT | Более дорогой корпоративный тариф Cursor (только если безопасность потребует) |
| Веб-чат-справка для **до 50** пользователей | Дорогое предложение ITG на $960/мес |
| Правила доступа и журнал вопросов в чате | Свой мощный компьютер с видеокартой для ИИ (можно после пилота) |
| Ежемесячный бюджет на сервер, подписки и ИИ-сервисы | Оплата внешних подрядчиков на внедрение |

Чат для 50 пользователей **в бюджете и в решении сейчас**. Включать его всем сразу не обязательно: сначала хаб и IT, потом чат поэтапно.

---

## 1. Что это такое и как внедряем

**Не** новая программа 1С и **не** замена разработчиков.  
Это **инструменты**, чтобы быстрее находить ответы по нашим конфигурациям и разгрузить аналитиков.

| Часть | Простыми словами |
|-------|------------------|
| Cursor | Умный редактор кода для разработчиков и аналитиков |
| Сервер-хаб | Наш компьютер в дата-центре: хранит выгрузки конфигураций и быстрый поиск по ним |
| Веб-чат | Сайт-справка для пользователей: «как провести документ», «зачем эта кнопка» |
| Тестовые базы (по желанию) | Отдельный сервер 1С только с **тестами**, без боевых данных |

**Порядок работ:**
1. Пилот: несколько человек, несколько конфигураций.  
2. Если полезно — все 15 IT.  
3. Чат: сначала 10–15 пользователей, проверка, затем до 50.

Изменения в рабочих конфигурациях — как сейчас, через хранилище 1С. ИИ **не** пишет сам в боевую систему.

## 4. Безопасность — главное для спокойствия

### Куда ходят данные

| Данные | Где лежат | Уходят ли наружу |
|--------|-----------|------------------|
| Выгрузки кода конфигураций | Наш сервер | Куски кода могут уйти в облако Cursor / ИИ при вопросе в редакторе или чате — как у любого такого инструмента |
| Данные клиентов в боевых базах | **Не подключаем и не индексируем** | Запрещено |
| ФИО, телефоны в вопросах чата | Стараемся отфильтровать до отправки в ИИ | Цель — не отправлять |

Мы **не обещаем** «ничего никогда не уйдёт в облако». Мы обещаем: **нет боевых баз**, жёсткие правила, журнал, отключение доступа.

### Кто куда заходит

| Кто | Как | При увольнении / уходе |
|-----|-----|-------------------------|
| IT (15) | Корпоративная сеть + личный ключ на сервер (только чтение) | Отключить сеть → убрать ключ → убрать компенсацию Cursor |
| Пользователи чата (до 50) | Логин в чат, **без** доступа к файлам кода | Отключить учётку чата |
| Боевая база через этот контур | Никто | — |

### Правила

- Нельзя вставлять в чат пароли, списки клиентов, выгрузки из боевой базы.  
- В Cursor включаем режим приватности.  
- Все вопросы веб-чата пишутся в журнал; руководство/админ видит использование.  
- Перед открытием чата на 50 человек — проверка службой безопасности (логи пилота).

### Чат для пользователей — ограничения

- Только консультации («как сделать»).  
- **Нельзя** менять код, выгружать клиентов, ходить в боевую базу.  
- Ограничение частоты вопросов; фильтр персональных данных.

## 5. Что смогут разные люди

| Возможность | Разработчик | Аналитик | Пользователь в чате |
|-------------|-------------|----------|---------------------|
| Спросить «где в системе лежит X» | да | да | да (простыми словами) |
| Понять влияние изменения | да | да | нет / только кратко в ответе |
| Самим менять боевую конфигурацию через ИИ | нет* | нет | **нет** |
| Видеть файлы кода на сервере | только чтение | только чтение | **нет** |
| Боевая база | **нет** | **нет** | **нет** |
| Выгрузка клиентов | **нет** | **нет** | **нет** |

\* Изменения в конфигурациях — как сейчас, через хранилище и обычный процесс.

**Можно спросить:** «Как провести документ?», «Зачем эта настройка?»  
**Нельзя:** «Выгрузи всех контрагентов», «Выполни запрос к боевой базе».

## 6. Решения по этапам

| Этап | Когда | Что решаем |
|------|-------|------------|
| **Сейчас** | До старта | Утвердить идею, бюджет (IT + чат на 50), правила безопасности, сервер Hetzner (не ITG $960) |

| **Позже по желанию** | — | Свой ИИ на своей мощности; более жёсткий корпоративный Cursor |
