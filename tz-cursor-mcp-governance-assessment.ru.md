Кратко: что утверждаем, кто обслуживает, сколько стоит, как с безопасностью. Технические детали доступа и хостинга - на отдельной встрече с IT и Cyber.

---

## Что утверждаем сейчас

| Входит | Не входит |
|--------|-----------|
| Сервер с поиском по выгрузкам конфигураций | Подключение **боевых** баз с данными клиентов |
| Cursor для 15 человек IT | Выдуманные лицензии продуктов 1С до официального прайса |
| Веб-чат-справка (до 50) в бюджетном контуре; включение - поэтапно | Дорогое предложение ITG (~$960/мес) как основной вариант |
| Правила использования и журнал чата | Внешние подрядчики на внедрение |

---

## 1. Что это

Не новая конфигурация 1С и не замена людей. Инструменты: быстрее находить ответы по нашим конфигурациям и разгрузить аналитиков.

| Часть | Смысл |
|-------|--------|
| Cursor | Редактор с ИИ для IT |
| Сервер | Хранит выгрузки и поиск по ним |
| Веб-чат | Справка для пользователей |

Порядок: пилот → вся IT-команда → чат поэтапно. ИИ не пишет сам в боевую систему; изменения конфигураций - как сейчас, через обычный процесс.

## 2. Кто занимается

| Роль | Фокус |
|------|--------|
| Владелец продукта 1С | Бюджет и решение «идём / стоп» |
| Александр | Внедрение и прикладная поддержка |
| Системный администратор | Сервер, сеть, доступы |
| Cyber / Security | Политики и проверки |
| IT-команда / пользователи чата | Пользуются по правилам |

Внешние внедренцы на старт не требуются. Зависимость от одного человека снимаем вторым админом и инструкциями (см. [FAQ](tz-cursor-mcp-leadership-faq.ru.md)).

---

## 3. Стоимость

Ориентир: около **$16 тыс./год** внешних затрат (сервер и бэкап, Cursor, ИИ-сервисы, запас). Установка своими силами в сумму не входит.

**Лицензии коммерческих продуктов фирмы «1С»** по поиску/ИИ **не закладываем:** продукт в тестировании, прайс 1С - не ранее октября 2026. При необходимости - отдельный запрос после публикации цен.

Площадку (выделенный сервер или Azure) согласуем с IT в рамках ориентира.

---

## 4. Безопасность

| Тема | Позиция |
|------|---------|
| Боевые базы | Не подключаем и не индексируем |
| Выгрузки кода | На нашем сервере; при вопросе в ИИ могут уйти **фрагменты** контекста - это норма для класса инструментов |
| ИИ-провайдеры | Cursor (модели через него); OpenRouter или аналог для чата и индекса; детали - [FAQ §2](tz-cursor-mcp-leadership-faq.ru.md) |
| Обучение моделей | Режим конфиденциальности вендора; договоры - с Cyber/юристами при необходимости |
| Доступ | IT и бизнес разделены; MFA и отзыв - по стандартам компании (детали с IT/Cyber) |
| Чат | Только консультации; журнал; поэтапное открытие |

Мы не обещаем «ничего никогда не уйдёт в облако». Мы обещаем: нет боевых данных клиентов, понятные правила, возможность отозвать доступ.

## 6. Этапы решения

| Когда | Решение |
|-------|---------|
| Сейчас | Идея, ориентир ~$16 тыс./год, правило про боевые базы |
| После пилота | Продолжаем на всю IT-команду или останавливаемся |
| Перед чатом на всех | Согласование доступа с IT/Cyber |
| Позже | Лицензии продуктов 1С - только если появятся прайс и потребность |

## Формулировка решения

> Утвердить запуск Cursor и поиска по выгрузкам наших конфигураций для IT-команды и (поэтапно) веб-чат-справки для пользователей, без подключения боевых баз; бюджетный ориентир около **$16 тыс./год** внешних затрат; внедрение своими силами; площадку и модель доступа согласовать с IT и Cyber.
