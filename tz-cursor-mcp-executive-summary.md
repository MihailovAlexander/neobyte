# Обоснование для руководства: Cursor + MCP 1С

**Приложение к:** [`tz-cursor-mcp-team.md`](tz-cursor-mcp-team.md)  
**Версия:** 1.0 · **Дата:** 2026-08-25  
**Заказчик:** Владелец продукта 1С  
**Формат:** одностраничное резюме для согласования бюджета

---

## Суть предложения

Внедрить **корпоративный AI-контур для команды 1С**: не «ChatGPT в браузере», а ассистент с **полным контекстом всех 15 конфигураций** — код, метаданные, связи объектов, документация платформы. Исходники и индексы на **собственном сервере**; доступ через **VPN**; при увольнении доступ отключается сразу.

---

## Проблема сейчас

| Факт | Последствие |
|------|-------------|
| **15 конфигураций**, код меняется **ежедневно** | Никто не держит всё в голове |
| Поиск «где используется объект / кто пишет в регистр» | Часы вместо минут на каждую задачу |
| Новый сотрудник | Месяцы входа в контекст |
| **50 пользователей** 1С | Одни и те же вопросы аналитикам, нагрузка на IT без масштабирования |

---

## Решение (простыми словами)

| Компонент | Для бизнеса |
|-----------|-------------|
| **Cursor + Pro** | Рабочее место разработчика/аналитика с AI в редакторе |
| **MCP Hub** (центральный сервер) | Общий «мозг» по 15 конфигурациям: поиск, impact-анализ, стандарты |
| **OneMCP на тестовых базах** (отдельный сервер 1С) | Ответы по живой **тестовой** ИБ, без риска для прода |
| **Web-чат** (фаза 2) | Справочная для 50 пользователей без участия аналитика |

---

## Что даёт ИИ команде

1. **Поиск по 15 базам за минуты** — использование объектов, цепочки проведения, вызовы процедур.
2. **Меньше ошибок при доработках** — видно, что сломается при изменении.
3. **Быстрее онбординг** — вопросы системе, а не только коллегам.
4. **Единые правила** — общие standards/rules для всех 15 человек.
5. **Проверка кода** — синтаксис, стиль, 1С:Напарник в том же контуре.
6. **Разгрузка аналитиков** (фаза 2) — пользователи спрашивают чат, а не пишут в личку.

**KPI пилота:** ускорение поиска по метаданным и коду **~×7** (опрос до/после, 15 человек).

## Масштаб и бюджет

| Показатель | Значение |
|------------|----------|
| Разработчики + аналитики | **15** |
| Конфигурации | **15** |
| Пользователи (фаза 2) | **50** |
| OPEX фаза 1 | **~$680–840/мес** |
| OPEX год (фаза 1 + частично фаза 2) | **~$15 000 + лицензии MCP** (TBD) |
| Сервер индексов (Hetzner AX102) | **€259/мес** |
| Cursor Pro | **$20/чел/мес** (компенсация в ЗП) |
| Развёртывание и поддержка | **внутренние силы**, в смету не входят |
| Сервер 1С (тест + OneMCP) | **отдельный хост**, отдельная строка бюджета |

**Сравнение:** один middle-разработчик 1С — порядка **150–250 тыс. ₽/мес** ФОТ. Весь AI-контур — **меньше 0,5 FTE**, при этом обслуживает **всю команду и все 15 баз**.

## Экономический эффект (оценка)

*Консервативные допущения для согласования бюджета, не аудит.*

| | |
|-|-|
| Экономия на поиск/разбор кода | **~30–45 мин/день** на человека |
| Команда × рабочие дни | **15 × ~22** |
| Экономия времени | **~165–247 ч/мес** |
| Условная стоимость часа | **$25–40** |
| **Эффект в месяц** | **~$4 000–10 000** |
| **Расходы (фаза 1)** | **~$700–850/мес** |
| **Ориентир ROI** | **~5–10×** (время vs прямые платежи) |

При **половине** заявленного эффекта проект окупается по времени команды. Дополнительно: меньше регрессий, быстрее релизы (сложнее посчитать, для бизнеса часто важнее).

## Этапы (снижение риска)

| Этап | Срок | Результат |
|------|------|-----------|
| **1. Пилот** | 1–3 нед | 3 конфигурации, 3–5 человек, первые замеры |
| **2. Тираж** | 4–8 нед | 15 конфигураций, вся IT-команда |
| **3. Стабилизация** | до 3 мес | SLA, мониторинг, тестовые базы + OneMCP |
| **4. Web для пользователей** | 4–6 мес | 50 человек, меньше нагрузки на аналитиков |

**Выход после пилота** возможен, если KPI не подтвердится — без «всё или ничего».

---

## Риски и контроль

| Риск | Как закрыто |
|------|-------------|
| Утечка кода | Свой сервер, VPN, отзыв SSH при увольнении |
| «AI наврёт» | Ответы по реальным объектам конфигурации; проверяет человек |
| Перегруз сервера | Индексация **ночью**; отдельный NVMe под индексы |
| Прод-данные | OneMCP только на **тестовых** базах |
| Стоимость | ~$15K/год vs ~$4–10K/мес экономии времени (оценка) |

---

## Что это не заменяет

- Не заменяет разработчика — **ответственность за прод** остаётся у человека.
- Не подключает боевые ИБ к «живому» MCP — только тест + индексы выгрузки.
- Качество ответов зависит от актуальности индекса (SLA: отставание **≤ 7 дней**).

---

## Решение одной фразой

> **За стоимость меньше половины одного разработчика — общий AI-контекст по 15 конфигурациям для всей команды, ускорение поиска и доработок в разы и поэтапный канал самообслуживания для 50 пользователей, с контролем доступа и возможностью остановиться после пилота.**
